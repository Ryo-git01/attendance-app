# 勤怠管理アプリ

iPhoneのSafariで使うことを想定したシンプルな勤怠管理Webアプリです。

## ファイル

- `index.html`：画面の構造
- `style.css`：デザイン
- `app.js`：勤怠処理・localStorage保存・編集・実働計算

## 仕様

- 出勤と退勤を交互に操作
- 出勤時刻は押した瞬間に取得し、localStorageへ即保存
- 打刻時刻を約1秒表示
- 退勤時に休憩時間を「分」で入力
- 0分も登録可能
- 登録後に出勤可能状態へ戻る
- 勤怠確認は「先々月・先月・当月」の3ヶ月
- 4ヶ月目に入ると最も古い月を自動削除
- 出勤・退勤・休憩から実働時間を自動計算
- 編集では出勤・退勤・休憩のみ変更可能
- 実働は自動再計算
- データはブラウザのlocalStorageに保存

## iPhoneでの利用

GitHub Pagesなどで公開したあと、Safariでページを開き、
共有メニュー → 「ホーム画面に追加」
でホーム画面から起動できます。

※ iOS/Safariの仕様上、JavaScriptからキーボードを強制的に開くことには制限があります。
休憩入力欄・編集欄は数字入力に適した `inputmode` を設定してあります。


## 給与計算アップデート
- 勤怠一覧で表示中の月を給与計算の対象にします。
- 初期値：基本給188,320円、残業元単価1,402円、手当30,000円、交通費250円/日。
- 残業は日8時間超と週40時間超を概算集計し、60時間まで1.25倍、超過分1.5倍で計算します。週は月曜始まりとして計算します。
- 法定休日の1.35倍計算は自動判定・自動加算しません。給与計算は概算です。
- 給与単価設定は attendanceSalarySettings_v1 に保存します。既存の勤怠データ保存キーは変更していません。
